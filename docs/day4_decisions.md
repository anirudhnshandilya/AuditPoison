# Day 4 decisions

- Implement EvidenceShield as a wrapper rather than modifying provider-specific clients.
- Keep the benchmark dataset frozen at 40 bundles for this engineering milestone.
- Do not use oracle or attack metadata during screening.
- Quarantine only hard provenance, scope, temporal, instruction, and authority failures.
- Require verified technical or operational citations before allowing a compliant verdict.
- Report clean-utility trade-offs alongside false-assurance reductions.
- Treat keyword results as smoke tests only; scientific results require real model runs and repeated trials.
